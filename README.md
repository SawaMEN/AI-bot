# AI-bot — бесплатный ИИ-бот для бесед ВКонтакте

Лёгкий бот для VDS с 1 ядром / 1 ГБ ОЗУ: учитывает последние сообщения разных участников, которые доступны сообществу, отвечает по упоминанию, позволяет каждому выбрать модель и свои настройки. Обработка ИИ — во внешних бесплатных API, не на VDS. Интерфейс и подсказки — на русском.

**Ограничение:** бесплатные API имеют квоты, зависят от региона и могут менять модели. Никаких пробных периодов, банковской карты и платных резервных моделей в проекте не предусмотрено. Не подключайте платный биллинг самостоятельно.

## Установка одной командой

Debian 12+ / Ubuntu 22.04+, systemd, sudo:

```bash
curl -fsSL https://raw.githubusercontent.com/SawaMEN/AI-bot/main/install.sh | sudo bash
```

Открыть русское меню управления: `sudo aibot`. Там можно подключить ВК, ввести отдельные API-ключи, **отметить разрешённые модели у каждого провайдера**, назначить основную, ограничить контекст и количество запросов. Для обновления повторите установочную команду.

## Бесплатные API и модели

| Провайдер | Разрешённый бесплатный доступ |
|---|---|
| GroqCloud | GPT-OSS 20B / 120B, Llama 3.1 8B, Llama 3.3 70B по квоте Free |
| Gemini API | Flash и Flash Lite по квоте Free |
| OpenRouter | Только `openrouter/free` и динамические `:free` с ценой $0 за вход и выход |
| Cloudflare Workers AI | GLM, Gemma, Nemotron в пределах бесплатных Neurons |
| Mistral Studio | Только Mistral Small по квоте бесплатного плана |
| **Z.ai — новый** | GLM-4.7-Flash и GLM-4.5-Flash ($0 за токены) |
| **SiliconFlow — новый** | Бесплатные Qwen 3.5 4B / Qwen 3 8B / Qwen 2.5 7B / DeepSeek R1 Distill Qwen3 8B |
| **ModelScope — новый** | Qwen 3.5 35B через бесплатную API Inference |

Проверяйте бесплатный режим в кабинетах провайдеров. SiliconFlow может потребовать верификацию личности, ModelScope — регистрацию. Внешние API и цены могут измениться. Источники: https://docs.z.ai/ , https://docs.siliconflow.cn/ , https://modelscope.cn/docs/model-service/API-Inference/intro .

Из прежней версии исключены неподтверждённые как бесплатные варианты: Custom API, Hugging Face с расходом платных токенов, Mistral Large. Даже старые сохранённые платные ID отфильтровываются на сервере.

## Права в ВК: что и где включить

1. Откройте **сообщество → Управление → Сообщения**; включите «Сообщения сообщества».
2. Там же → **Настройки для бота**: включите «Возможности ботов» и «Разрешать добавлять сообщество в беседы».
3. В **Управление → Настройки → Работа с API → Ключи доступа** создайте ключ сообщества с правом на сообщения. Укажите его только на сервере в `sudo aibot`. Никогда не отправляйте ключ через ВК.
4. В **Long Poll API** включите Bots Long Poll и отметьте события **`message_new`** и **`message_event`** (для кнопок).
5. Добавьте сообщество в беседу. **Администратор беседы** должен открыть название беседы → участники → сообщество → права, выбрать **«Доступ ко всей переписке»** или назначить администратором. При доступе «Только упоминания» бот не сможет учитывать разговор всех участников.
6. Один участник пишет обычную реплику; другой упоминает сообщество и спрашивает «а как ты думаешь?» — бот должен учитывать первую реплику. Более старые, недоставленные VK сообщения восстановить нельзя.

Названия меню могут немного отличаться в мобильной и браузерной версиях ВК. **Та же инструкция доступна прямо в ВК:** упомяните сообщество и напишите `права`, либо нажмите кнопку «Права и подключение».

## Как обращаться БЕЗ слова «бот»

В беседе достаточно упоминания сообщества в начале, середине или конце сообщения:

```text
[club123|Мой ИИ] как думаешь?
@club123, найди кратко информацию по теме
Какой вариант выбрать, [club123|Мой ИИ]?
[club123|Мой ИИ] меню
[club123|Мой ИИ] права
```

Замените `123` на ID сообщества или выберите сообщество через штатную функцию упоминания ВК. Старые обращения «бот ...» тоже сохранены, но **не обязательны**.

## Кнопки ВК

Команда **«меню» с упоминанием** показывает inline callback-кнопки: **Выбрать ИИ**, **Мои настройки**, **Поиск**, **Стиль ответа**, **Контекст**, **Настройки беседы**, **Права и подключение**, **Помощь**. Модели листаются по страницам; выбор и настройки доступны кнопками. Нажатие callback-кнопки не создаёт сообщения от участника (работает при включённом `message_event`); бот отвечает с дальнейшими кнопками.

Личные настройки доступны каждому, общие настройки беседы — только её администраторам (права проверяются через VK API). Приоритет: **личные → беседы → сервер**. Серверные ограничения нельзя снять в беседе.

Текстовые команды также работают: `бот модели`, `бот модель 2`, `бот поиск авто`, `бот стиль кратко`, `бот диалог модель 1`. Без слова «бот» используйте эти команды после упоминания.

## История и приватность

По умолчанию SQLite хранит последние сообщения бесед 7 дней; в запрос ИИ отправляются до 30 последних сообщений за 24 часа. Беседы разделены по VK peer_id. Фрагменты переписки передаются стороннему API: заранее предупредите участников. Есть ограничение частоты запросов, автоматическая очистка истории и поиск DDGS. Нет открытых входящих портов.

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Программные тесты проверяют маршрутизацию и настройки без действующих ключей. После установки требуется проверить реальные подключения ВК и AI API.
