# AI-bot — ИИ-помощник для бесед ВКонтакте

Лёгкий бот на Python для небольших VDS (от 1 vCPU, 1 ГБ ОЗУ): читает **доступные ему сообщения всех участников**, хранит контекст раздельно по беседам и отвечает только при обращении («бот, а как ты думаешь?»), упоминании сообщества или ответе на сообщение бота. По запросу ищет сайты и прикладывает ссылки на найденные источники.

**Статус:** первый рабочий MVP, не проверенный пока с реальным токеном ВК и API. Бесплатные тарифы ИИ имеют квоты и зависят от региона. Проект не обеспечивает неограниченную работу ИИ бесплатно.

## Установка одной командой

Ubuntu 22.04+/Debian 12+ с systemd, Python 3.10+, root/sudo и сетевым доступом к GitHub, PyPI, VK и выбранному ИИ-провайдеру:

```bash
curl -fsSL https://raw.githubusercontent.com/SawaMEN/AI-bot/main/install.sh | sudo bash
```

Установщик создаст отдельного непривилегированного пользователя, Python venv, systemd-сервис и запустит интерактивный мастер настройки. **Внимание:** перед выполнением рекомендуем просмотреть `install.sh`; он запрашивает права root. Если терминал недоступен, запуск мастера вручную: `sudo aibot setup`.

После установки меню настроек:

```bash
sudo aibot
```

Дополнительные команды: `sudo aibot api`, `sudo aibot vk`, `sudo aibot behavior`, `sudo aibot restart`, `sudo aibot status`, `sudo aibot logs`. Обновление из меню (пункт 8).

## Подключение VK

1. Создайте/используйте сообщество ВК. Включите «Сообщения сообщества», «Возможности ботов», «Разрешать добавлять сообщество в беседы».
2. Включите **Bots Long Poll API** и событие **message_new** («Входящее сообщение»). Создайте **токен сообщества** с правом на сообщения.
3. Добавьте сообщество в нужные беседы и выдайте ему **доступ ко всей переписке** либо права администратора: без этого контекст всех участников будет неполным. Бот не может видеть сообщения, написанные до его добавления, или скрытые настройками VK.
4. Введите токен и числовой ID сообщества в мастере установки. Выберите ИИ-провайдера и введите его API-ключ.

Используется исходящее подключение Bots Long Poll, поэтому **открывать входящие порты не требуется**. В беседе: «бот, сравни два варианта», «бот, а как ты думаешь?», «бот, найди последние новости о…». Приватные сообщения, доставленные боту, тоже поддерживаются.

## Провайдеры в русском меню

- GroqCloud (по умолчанию: `openai/gpt-oss-20b`)
- Google Gemini (`gemini-2.5-flash-lite`)
- OpenRouter (`openrouter/free`; не добавляйте платные запасные модели)
- Cloudflare Workers AI (понадобится Account ID)
- Любой OpenAI-совместимый endpoint через HTTPS

Выбор **не означает**, что у провайдера в любой стране доступен бесплатный аккаунт, а у модели — бесплатная квота. Перед подключением убедитесь, что используете именно бесплатный тариф и бесплатную модель. Токены ChatGPT Plus этим проектом не используются.

## Контекст, приватность, пределы

- SQLite хранит тексты доставленных событий `message_new` (по умолчанию **7 дней**) и изолирует каждую беседу по `peer_id`.
- В запрос отправляются последние **30 сообщений за 24 часа** текущей беседы, включая сообщения других участников и ответы бота. Эти данные передаются выбранному внешнему ИИ-провайдеру; участникам стоит сообщить об этом заранее.
- Дедупликация событий, ограничение **50 ИИ-запросов в час** на всю установку и **15 секунд** между ответами в одной беседе.
- Поиск (DDGS) включается только для фраз вроде «найди», «поищи», «новости», «источники». Передаются краткие сниппеты, **не полные тексты страниц**; сайты и поисковики могут блокировать автоматический поиск.
- Переписка сохраняется только после присоединения бота при наличии прав. Автоочистка — по сроку хранения; в меню доступна ручная очистка всей истории.
- Секреты в `/etc/ai-bot/config.json` с правами `root:aibot 0640`; сервис запускается как пользователь `aibot`. База: `/var/lib/ai-bot/history.db`.
- Если поиск не сработал, бот не должен изображать актуальную интернет-проверку; если бесплатная квота исчерпана, выводит ошибку.

## Для разработчиков

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Архитектура: `bot.py` — события VK; `ai_bot/core.py` — история и настройка; `providers.py` — разные API; `search.py` — веб-поиск; `cli.py` — русское меню.
