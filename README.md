# AI-bot — нативный Go-бот для бесед ВКонтакте

**Основная реализация: Go 1.27.** VK Bots Long Poll, callback-кнопки, бесплатные облачные ИИ, русский мастер настройки, SQLite, локальная веб-панель и очереди работают в одном бинарном файле. Проект рассчитан на VDS 1 vCPU/1 ГБ RAM, где параллельно работает VPN.

## Единое автоматизированное меню (v1.5.6)

```bash
sudo aibot menu
```

Главное меню разделено на **Автоматическую настройку**, **Подключения**, **Поведение**, **Диагностику**, **Веб-панель**, **Обслуживание** и **Помощь**. Ранее разбросанные по меню проверки сетевого соединения, языка и ключей объединены в один порядок: **сначала доступность HTTPS с VDS → затем защищённый ввод API-ключа → проверка каждой бесплатной модели на русский → автоматическое сохранение только при успехе**. Смена ключа при ошибке проверки не повреждает существующие настройки.

Модели, не давшие ответа на русском даже после двух разных русскоязычных запросов, автоматически **исключаются из рабочего каталога бота на сервере**; временные ошибки 401/403, 429, таймауты и недоступность сети не считаются доказательством отсутствия русского языка. Исключённые модели можно повторно проверить вручную; периодическая перепроверка языковых отказов — раз в 7 дней. Сервисные API-ключи не хранятся в файле проверки. Веб-каталог исходных моделей остаётся доступным для повторной проверки, чтобы ошибочная или устаревшая классификация не была необратимой.

Меню работает по принципам современного интерфейса Archinstall: в SSH-терминале можно перемещаться **стрелками ↑/↓ или j/k**, нажимать **Enter** для выбора, **Esc или 0** для возврата, **/** для поиска по пунктам. Для выбора сразу нескольких бесплатных ИИ-моделей используйте **Space** и подтвердите **Enter**. В меню есть текущие состояния ВК, провайдеров и реально работающих моделей, описание действий и подсказки по следующему шагу. Ключи API не выводятся.

Когда количество задач известно (например, проверка всех ИИ-моделей), отображается **настоящий процентный прогресс-бар** и имя проверяемой модели. При ожидании ответа каталога, диагностике или настройке службы появляется индикатор выполнения без выдуманного процента. Интерактивный установщик также показывает ход фактической загрузки файлов. Статусы ошибок отображаются после выполнения операций.

В терминалах без TTY, при `TERM=dumb` или `AIBOT_PLAIN=1` автоматически используется обычное нумерованное меню и текстовый прогресс. `NO_COLOR=1` отключает цвета, сохраняя управление с клавиатуры. Python, Textual, ncurses и дополнительные процессы на сервере не требуются.

## Меню внутри ВКонтакте (v1.5.7)

В беседе напишите **«бот меню»** или нажмите кнопку «Меню» под ответом. В личных сообщениях сообщества достаточно написать **«меню»**. Главное меню теперь короткое, с понятными кнопками: **Мои настройки**, **Для беседы**, **Выбрать ИИ**, **Помощь**, **Подключение ВК**.

Личные настройки и настройки беседы открываются отдельными экранами. Сначала выбирается параметр — модель, поиск, формат ответа, контекст или резервный ИИ — затем конкретное значение. После применения бот показывает обновлённые настройки и кнопки этого же раздела. Больше не нужно запоминать текстовые команды. В выборе модели есть рекомендуемая кнопка **«Авто»**, список содержит только проверенные модели. Сброс настроек требует отдельного подтверждения.

Для настройки **всей беседы** бот повторно проверяет права администратора при каждом изменении; личные параметры доступны всем участникам. В личных сообщениях ВК меню по возможности обновляется в том же сообщении; в групповом чате экран не перезаписывается, чтобы разные участники не мешали друг другу. Старые текстовые команды продолжают работать.

## Автоматическое обновление при появлении релиза

`ai-bot-update.timer` проверяет новые GitHub Releases примерно **раз в 5 минут** (`OnUnitInactiveSec=5min` с небольшой случайной задержкой) вместо одного раза в час. Скачивание полного бинарника выполняется **только при изменении контрольной суммы**. Обновление проверяется по SHA-256, выполняется атомарно и откатывается при неудачном запуске службы.

Для **уже установленного бота** после перехода на v1.5.7 **один раз повторно запустите `install.sh`**, чтобы заменить старый защищённый systemd-таймер: автоматическое обновление бинарника не всегда может изменить файлы `/etc/systemd/system` из-за `ProtectSystem=strict`. Настройки и история сохраняются. Новые установки получают интервал 5 минут сразу. Посмотреть расписание: `systemctl list-timers ai-bot-update.timer`.

## ВК: крупные постоянные кнопки как в «Дайвинчике» (v1.5.8)

В личных сообщениях с сообществом бот теперь показывает **постоянное меню под полем ввода** (не inline-кнопки под отдельным сообщением). Кнопки сгруппированы в короткие экраны и выделены цветом: **«Выбрать ИИ»**, **«Мои настройки»**, **«Помощь»**, **«Меню»**. На экране настройки доступны быстрые действия «Модель», «Поиск», «Стиль», «Контекст», «Резерв», «Сброс» и «Главное меню». Все изменения осуществляются в несколько нажатий, а клавиатура остаётся доступной после ответа ИИ. Кнопка «Автоматически» выбирает подходящую работающую модель без ручного выбора.

Кнопки используют `action.type=text` и `payload` для команд — это штатный механизм **постоянной клавиатуры ВК**. В личных сообщениях больше не нужно упоминать бота: достаточно написать обычный вопрос. В групповых чатах меню остаётся **inline** под сообщениями, чтобы не занимать постоянную клавиатуру всех участников. Для настройки параметров всей беседы по-прежнему нужны права администратора. Сохранились текстовые команды и старые callback-кнопки: нажатие устаревшей кнопки откроет новое меню.

## Исправление «Нет доступных моделей» (v1.5.9)

Исправлены три ситуации, когда API-ключ и провайдер уже подключены, но ВК показывает пустой список ИИ:

- Веб-панель при подключении провайдера без ручного выбора модели автоматически включает подбор его бесплатных моделей и **перезапускает службу** после сохранения (раньше работающий бот продолжал использовать старую конфигурацию).
- CLI-проверка и работающий бот больше не перезаписывают результаты тестирования моделей друг друга: проверенные результаты объединяются под межпроцессной блокировкой и сразу становятся видны другим процессам.
- Модели выбранного по умолчанию ИИ проверяются первыми. В ВК пустой список различает ещё не проверенные модели, ошибки API/квоты и отсутствие подтверждённого русского ответа; доступна кнопка **«Обновить список»**.

Чтобы немедленно проверить состояние со своего VDS:

```bash
sudo aibot check-ai
sudo aibot restart
sudo aibot logs
```

В список ВК попадают **только модели с подтверждённым ответом на русском языке**. Одна лишь запись API-ключа не подтверждает, что модель доступна. Сбой из-за квоты или сети не считается отсутствием русского языка. Ключи в отчёты проверки не выводятся.

## Ошибка: все подключённые ИИ недоступны (v1.5.10)

Если в ВК выводится «моделей на проверке: N, ошибки API: N», это означает, что реальные запросы из VDS к подключённым ИИ не прошли проверку — **не обязательно, что API-ключ не сохранился**. Теперь бот показывает причину по каждой модели отдельно: HTTP 401/403 (ключ/права), 429 (квота), 402 (баланс), 404/410 (модель отсутствует), 400/422 (формат запроса), сетевые ошибки, отсутствие текста или ответ без подтверждённого русского языка. Старые результаты с общим статусом «Ошибка API» уточняются при следующей проверке.

```bash
sudo systemctl start ai-bot-update.service
sudo aibot version
sudo aibot check-ai
sudo aibot restart
```

`sudo aibot check-ai` принудительно проверяет модели на сервере и теперь выводит **причину для каждой неработающей модели**, без раскрытия API-ключей. ВК отображает эти причины при выборе моделей. Бот также поддерживает текстовые массивы в OpenAI-совместимых ответах; ранее такой успешный ответ мог ошибочно считаться пустым.

При сообщении HTTP 429 проверьте лимиты провайдера, при 401/403 — ключ и права, при 400/422 — совместимость модели и API, при сетевых ошибках — `sudo aibot check-ai network`. Не пересылайте секреты из конфигурации или токены сообщества.

## Раздельное меню ИИ и функций; широкий каталог бесплатных моделей (v1.5.11)

Меню ВК теперь состоит из **отдельных экранов**: «🤖 ИИ» (только модель и режим «Авто»), «🧰 Функции» (поиск, стиль, контекст, резерв), «⚙ Настройки» (личные параметры и сброс), «❓ Помощь». В групповых беседах сохранены встроенные callback-кнопки, в личных — постоянная клавиатура.

В ВК **нет сообщений об API-ключах, сетевых проверках, квотах и командах Linux**. Все технические подробности доступны администратору в консоли, не обычным пользователям. При недоступности моделей экран выбора показывает только короткий нейтральный статус, а неподтверждённые варианты не имеют кнопки выбора.

Каталог расширен: добавлены действующие бесплатные текстовые варианты Gemini; для OpenRouter (`ID:free`, $0 за вход и выход) и Pollinations (нулевая цена на вход и выход) бот динамически отбирает до **30 мультиязычных кандидатов на провайдера**, отфильтровывая модели модерации, эмбеддингов, аудио и модели неизвестных языковых семейств. Модель появляется в ВК **только после успешного реального API-запроса на русском**, результаты кэшируются и периодически перепроверяются. При неуспешной проверке модель просто скрыта. Наличие 30 кандидатов в каталоге **не гарантирует 30 одновременно доступных моделей**, поскольку бесплатные варианты, ключи, квоты, география и результаты русскоязычной проверки зависят от сервиса.

Важно: большинство бесплатных сервисов требуют своего API-ключа, и нулевая цена может сопровождаться дневными лимитами. Не добавляйте платные тарифы или данные банковской карты ради увеличения списка.

## Раздельная консоль и постоянные кнопки ВК (v1.5.12)

**Консоль `sudo aibot menu`:** главное меню содержит отдельные разделы **«ИИ и модели»**, **«Функции бота»**, **«ВКонтакте»**, «Диагностика», «Веб-панель», «Обслуживание», «Помощь» и «Мастер настройки». Раздел ИИ — только провайдеры, бесплатные модели и основной выбор. «Функции» — отдельные подменю «Поиск и резерв», «Контекст и история», «Лимиты и частота». ВК — сообщество, токен, Long Poll и инструкция. `sudo aibot api`, `sudo aibot behavior` и `sudo aibot vk` остаются доступны для автоматизации.

**ВКонтакте:** постоянная клавиатура **под полем ввода** работает как в личных сообщениях, так и **в беседах сообщества**. Используется `inline:false`, `one_time:false` и стандартные текстовые кнопки ВК (`message_new` с `payload`), а не прикреплённые к ответам callback-кнопки. Нажатие кнопки с `payload` не требует упоминания бота; обычные сообщения участников беседы по-прежнему игнорируются без обращения к боту.

**Важно для групповых бесед:** клавиатура ВК — **общая для участников**. Поэтому под беседой только общие пункты «ИИ беседы», «Функции беседы», «Помощь», а личные предпочтения редактируются в личных сообщениях сообществу. Изменять модель, поиск, стиль, контекст, резерв и выполнять сброс общих настроек через кнопки может только администратор беседы. Проверка прав происходит на сервере при каждой операции, а не по данным кнопки.

При обновлении сохранены конфигурация, API-ключи и история. Для установки новой клавиатуры в ранее созданную беседу отправьте **«бот меню»**; далее она останется снизу в ВК. На некоторых клиентах ВК внешний вид клавиатуры может отличаться.

## Этап 2/3: интеллектуальный выбор ИИ, контекст, поиск (v1.5.14)

В автоматическом режиме бот учитывает накопленную успешность ответов, среднюю задержку и сложность вопроса при выборе из уже проверенных русскоязычных бесплатных моделей. Ручной выбор участника и администратора беседы сохраняет приоритет; модель, заданная администратором сервера, используется как начальная предпочтительная, пока нет достаточно измерений для автоматического выбора. Метрики сохраняются локально в SQLite без ответов или ключей.

Контекст сообщений ограничивается по символам Unicode, не разрывает UTF-8, сохраняет цепочки ответов и короткие цитаты более ранних важных договорённостей. Имена участников при возможности извлекаются через `users.get` ВК; при недоступности остаются числовые обозначения, не блокируя ответ.

Поиск одновременно проверяет DuckDuckGo и русскую Википедию, удаляет дубли, приоритизирует совпадения по запросу и ограничивает текст результатов. Результаты поиска считаются внешними недоверенными данными, без гарантии актуальности и без заявления о проверке страницы.

## Установка или обновление

Ubuntu/Debian с systemd и архитектурой Linux amd64/arm64:

```bash
curl -fsSL https://raw.githubusercontent.com/SawaMEN/AI-bot/main/install.sh | sudo bash
```

Установщик загружает **готовый Go-бинарник последнего релиза GitHub Release** и проверяет SHA-256. Компилятор Go, Python и Docker на VDS не нужны. Если бинарника в релизе ещё нет, скрипт не заменяет старую версию. Существующие `/etc/ai-bot/config.json` и `/var/lib/ai-bot/history.db` сохраняются; при ошибке запуска предусмотрена попытка отката.

```bash
sudo aibot menu       # главное меню ✓ ВКЛ / ✗ ВЫКЛ
sudo aibot setup      # первая настройка, шаг за шагом
sudo aibot guide      # где в ВК найти сообщество, ID, токен и Long Poll
sudo aibot next       # что ещё осталось настроить?
sudo aibot doctor     # диагностика ✓/✗ с подсказками
sudo aibot check-ai  # проверка ВСЕХ моделей с VDS, вывод только доступных
sudo aibot check-ai network  # только сеть без расхода квоты
sudo aibot web        # локальная веб-панель через SSH
sudo aibot logs       # подробные сообщения об ошибках
```

### Проверка ИИ с сервера

`sudo aibot check-ai network` проверяет DNS, прямое TCP-соединение и TLS с проверкой сертификата к API каждого включённого провайдера непосредственно **с VDS**, где выполняется команда. Запросы к моделям не отправляются.

`sudo aibot check-ai` **проверяет каждую включённую бесплатную модель отдельно** реальным API-запросом с VDS, проверяет авторизацию, ответ и русский язык. После проверки показывает **только список успешно ответивших моделей**. Сообщает точный этап отказа: DNS, TCP, TLS, авторизация, квота, недоступная модель или отсутствие русского ответа. **Эта проверка расходует бесплатную квоту ИИ.** Проверка может занять время, если провайдеры не отвечают. Для динамических провайдеров сначала обновляется каталог.

В `sudo aibot menu` тесты находятся в разделе **«Диагностика»**, а настройка API — в **«Подключения» → «Бесплатные ИИ»**.

Проверенные результаты хранятся в `/var/lib/ai-bot/model-health.json` (без API-ключей). Список в VK и административном меню содержит только успешно проверенные модели не старше суток. Сканирование идёт автоматически после запуска бота и затем каждый час с повторными проверками: успешно работающие модели перепроверяются через 12 часов, неработающие из-за API/сети — через 30 минут; модели без подтверждённого русского — через 7 дней. Если ключ или аккаунт провайдера изменён, прежний результат не засчитывается. Сразу после первой настройки список может быть пустым, пока сервер проверяет модели. Для немедленной полной перепроверки: `sudo aibot check-ai`. Это расходует бесплатную квоту для каждой модели. В случае многих моделей проверка может быть длительной. Настройки, ключи и история не изменяются. Сетевая проверка использует прямое соединение; запрос API может учитывать HTTPS-прокси из окружения процесса. Если у службы особые сетевые настройки, результаты запуска из терминала могут отличаться.

### Автообновление

После однократного запуска установщика новая служба `ai-bot-update.timer` примерно каждые 5 минут проверяет GitHub Releases. Сначала скачиваются SHA-256 суммы; если бинарник не изменился, программа не загружается и бот не перезапускается. При обновлении скачанный бинарник и сам скрипт автообновления проверяются по SHA-256. Бинарник заменяется атомарно, активные службы бота и панели перезапускаются, а при ошибке запуска восстанавливается прежняя версия. Данные, ключи и настройки не затрагиваются. Изменения кода в main станут доступны на сервере после публикации GitHub Release (и его успешной сборки).

```bash
sudo systemctl status ai-bot-update.timer       # активен ли таймер
sudo systemctl start ai-bot-update.service      # проверить обновление сейчас
sudo journalctl -u ai-bot-update -n 60 --no-pager
sudo systemctl disable --now ai-bot-update.timer  # отключить автообновление
```

Во время запроса к ИИ бот показывает индикатор «печатает» в беседе ВКонтакте, обновляя его каждые 5 секунд до ответа. Отдельные служебные сообщения в чат не отправляются. Отображение индикатора зависит от клиента ВК и разрешений сообщества.

## С чего начать?

Начиная с версии 1.5.0, меню показывает выполненные шаги через **✓ Готово** и проблемы через **✗ Не настроено**, а рядом со всеми переключателями — **✓ ВКЛ** / **✗ ВЫКЛ**.

1. **Создайте сообщество ВК.** Это отдельная страница-группа или паблик, от имени которой отвечает бот, **не беседа с участниками**.
2. **Найдите ID и токен:** в управлении сообществом выберите «Настройки» → «Работа с API» → «Ключи доступа». Числовой ID — например `123456` из ссылки `vk.com/club123456`.
3. **Включите сообщения и события Long Poll** — `message_new` и `message_event`.
4. **Выберите бесплатного ИИ** в пункте 2 меню и включите его. ИИ-сервис (например Groq) — не сообщество ВК.
5. **Добавьте сообщество в беседу**, разрешите ему доступ к сообщениям и напишите упоминание `[club123456|Бот], привет!`.

Подробная инструкция с расположением всех пунктов в ВК: [Первая настройка — от создания сообщества до первого ответа](docs/QUICKSTART.md). В терминале её можно открыть командой `sudo aibot guide`.

### Проверка моделей на русском языке

```bash
sudo aibot check-models
```

Команда отправляет **реальные русские тестовые запросы** через ваши API-ключи, показывает результат для каждой подключённой модели и сохраняет исключения в конфигурацию. Модель, которая дважды ответила без правильного ответа на русском, исключается из выбора, в том числе автоматического. Ошибка ключа, таймаут, HTTP 429 или временное отключение не означают отсутствия русского языка: такие модели не удаляются, но диагностика показывает причину. Для применения изменённого списка запустите `sudo aibot restart`. Тестовые запросы расходуют бесплатную квоту провайдера.

Проверка также доступна в `sudo aibot menu` → «Подключить бесплатный ИИ / выбрать модель» → «Проверить русский язык и доступность моделей». Бот во время обычного общения автоматически отклоняет явный англоязычный текст в ответ на русский вопрос и пробует другую подключённую модель, если резерв разрешён. Ответы кодом, числами и явные просьбы перевести на английский язык не блокируются.

**Изменения реестра:** удалены модели Groq Llama 3.1/3.3, поддержка которых прекращена 16 августа 2026 года, и AI Horde с непроверенными волонтёрскими моделями. Автовыбор `openrouter/free` исключён, так как он выбирал произвольные модели без контроля языка. Динамические каталоги ограничены семействами многоязычных текстовых моделей, но их окончательную пригодность проверяет команда выше.

## Что делает бот

- Учитывает последние сообщения **разных участников** беседы (если ВК разрешил доступ ко всей переписке).
- Отвечает **по упоминанию сообщества** в начале, середине или конце фразы, без слова «бот».
- Даёт выбирать облачные ИИ-модели каждому участнику, отдельно от настроек беседы.
- Показывает **inline callback-кнопки ВК**: выбор модели, поиск, стиль, контекст, резервная модель, настройки беседы.
- Администратор беседы управляет общими настройками; обычные участники — только личными.
- Использует **только разрешённые бесплатные модели** из реестра `go/providers.json`, а динамические API принимает лишь с подтверждённой нулевой ценой.
- Реализует лимиты API на весь сервер, одного участника и беседу, а также максимум одну резервную попытку у другого разрешённого бесплатного провайдера.
- Хранит историю и очередь необработанных обращений в SQLite, сохраняет позицию VK Long Poll для восстановления после перезапуска.
- Имеет поиск в интернете через DuckDuckGo HTML; если поисковик не отвечает или не возвращает результатов, использует публичный API Википедии как резервный источник.

## Бесплатные ИИ

**9 источников:** GroqCloud, Google Gemini, OpenRouter, Cloudflare Workers AI, Mistral Studio Free, Z.ai, SiliconFlow, ModelScope, Pollinations.

В `sudo aibot menu` → «Бесплатные провайдеры и модели» вставьте ключ бесплатного аккаунта (для AI Horde возможен анонимный режим) и включите **автоподбор бесплатных моделей**. Никаких платных API или автоматического перехода на платный тариф не предусмотрено. **Не подключайте карту и pay-as-you-go:** внешний провайдер может изменить тариф. AI Horde исключён: у произвольных волонтёрских моделей нет проверяемой гарантии поддержки русского языка.

## Права ВКонтакте

**Сообщество** — страница ВК (группа/паблик), от имени которой отвечает AI-bot. **Беседа** — чат, куда добавляют сообщество. Это не одно и то же.

Смотрите [подробную пошаговую инструкцию](docs/QUICKSTART.md): как создать сообщество, найти числовой ID, получить токен, включить «Сообщения сообщества» и Long Poll, пригласить сообщество в беседу и выдать ему доступ к сообщениям.

В терминале: `sudo aibot guide`. Чтобы увидеть следующий шаг именно вашей установки: `sudo aibot next`. Пункты управления ВК могут называться немного иначе в веб-версии и мобильном приложении.

## Управление: по домену с HTTPS или только терминал

Все функции управления доступны в **`sudo aibot menu`**. В пункте 8 можно выбрать доменную HTTPS-панель или локальный режим. Никаких публичных портов для самого VK-бота не требуется.

### Веб-панель по домену с бесплатным автоматическим сертификатом

Для отдельного домена, например `bot.example.com`, создайте DNS A/AAAA-запись на VDS. Доступность портов **80 и 443** извне необходима для обычного HTTPS и проверки сертификата Let's Encrypt/ZeroSSL. Сертификаты выдаёт и продлевает **Caddy**. Установите Caddy из проверенного пакета дистрибутива (Ubuntu/Debian: `sudo apt install caddy`), затем:

```bash
sudo aibot panel setup bot.example.com
sudo aibot panel status
```

Мастер проверяет формат домена, наличие Caddy, системного пользователя `caddy`, занятость 80/443 и валидность конфигурации Caddy. Если установленный пакет Caddy включил свой стандартный `caddy.service`, и вы **точно знаете**, что тот не обслуживает другие сайты, предварительно отключите только его командой `sudo systemctl disable --now caddy`. AI-bot не делает этого автоматически. Он создаёт **только** службы `ai-bot-panel.service` и `ai-bot-panel-tls.service`. Не меняет правила файрвола, настройки VPN или существующий системный `caddy.service`. Если VPN уже использует 443, настройка **отказывается от установки**: используйте терминал или SSH, а не отключайте VPN.

При первоначальной настройке показываются адрес `https://bot.example.com`, логин `admin` и уникальный пароль. Пароль показывается один раз; на диске сохраняется только SHA-256-хеш в `/etc/ai-bot/panel.json` с правами `0600`. Go-панель слушает **только 127.0.0.1:8765**, а доменная авторизация разрешает только HTTPS через Caddy.

Внимание: запуск Caddy не гарантирует мгновенную выдачу сертификата. DNS должен указывать на этот VDS, 80/443 должны быть доступны извне; проверьте журнал `sudo journalctl -u ai-bot-panel-tls -n 50 --no-pager`.

Отключение веб-доступа с сохранением работы бота:

```bash
sudo aibot panel off
sudo aibot panel status
```

Чтобы сменить домен и пароль, сначала отключите панель, затем `sudo aibot panel reset` и повторно настройте домен. Службы других приложений и сертификаты сторонних веб-серверов не трогаются.

### Только терминал или локальная панель по SSH

Терминал без публичного HTTP-сервиса: `sudo aibot menu`. Веб-панель по SSH без домена и без открытых портов:

```bash
ssh -L 8765:127.0.0.1:8765 USER@SERVER
sudo aibot web
```

Откройте на компьютере `http://127.0.0.1:8765`; логин `admin`, временный пароль показывается в терминале. Этот режим работает **только пока запущена команда**. Он не может работать одновременно с постоянной доменной панелью на том же локальном порту.

## Совместимость с Python

Go использует **те же пути и схему SQLite**, что и предыдущая Python-версия. Данные, настройки моделей, личные/чатовые предпочтения, сохранённые сообщения и ожидающие запросы сохраняются. Исходники Python сохранены в ветке [`archive/python-last-main`](https://github.com/SawaMEN/AI-bot/tree/archive/python-last-main) и истории Git для отката, но установленный Go-бинарник не запускает Python. Для перехода в случае сбоя установщик старается восстановить прежний systemd-сервис.

## Разработка и тесты

```bash
go mod tidy
go test ./go/...
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o ai-bot ./go
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -o ai-bot-arm64 ./go
```

Исходники только актуальной реализации находятся в `go/`; рабочие образы генерируются в GitHub Actions и прикладываются к релизу. **Интеграцию с реальными ключами ВК и провайдеров необходимо проверять на сервере** — юнит-тесты не гарантируют доступность внешних сервисов.

## Приватность

Части переписки передаются выбранному внешнему ИИ и, если включён резерв, могут уйти второму ИИ. Предупредите участников и при необходимости отключите резервный провайдер. Для закрытых чатов не включайте AI Horde. Ключи API хранятся только в серверной конфигурации с ограниченным доступом и не возвращаются пользователям ВК.
