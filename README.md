# AI-bot — бесплатный ИИ-помощник в беседах ВКонтакте

Лёгкий Python-бот для VDS с 1 vCPU / 1 ГБ RAM. Облачный ИИ обрабатывает текст вне сервера, бот хранит контекст доступных сообщений участников в SQLite. Для беседы: **«бот, а как ты думаешь?»** — бот читает последние сообщения и отвечает по теме.

**Статус:** MVP. Тесты выполняются без реальных токенов; реальную работу VK и каждого внешнего API нужно проверить после настройки. Бесплатность зависит от тарифа/региона/модели. Никаких обещаний неограниченного бесплатного API.

## Установка одной командой

Ubuntu 22.04+ или Debian 12+ (systemd, Python 3.10+). Понадобится SSH/root, доступ к VK и провайдеру.

```bash
curl -fsSL https://raw.githubusercontent.com/SawaMEN/AI-bot/main/install.sh | sudo bash
```

Ввод токенов и выбор моделей произойдут в русскоязычном мастере. Нет терминала — `sudo aibot setup`. После установки:

```bash
sudo aibot
```

В меню: «Подключить ВК», «Разрешённые провайдеры и модели», «Контекст, поиск и лимиты», «Состояние», «Журнал», «Обновить». Для обновления уже установленного проекта повторите команду установки или пункт 8 в меню.

## Настройка ВК

1. В сообществе откройте сообщения, включите Bots Long Poll API и событие `message_new`.
2. Создайте **токен сообщества** с правами «Сообщения»; используйте его и числовой ID сообщества в мастере.
3. Разрешите добавление бота в беседы и дайте ему **доступ ко всей переписке** либо назначьте администратором беседы. Бот видит только события, разрешённые ВКонтакте; история до присоединения не импортируется.
4. Добавьте сообщество в беседу. Входящие порты на VDS не требуются — бот сам подключается к VK Long Poll.

## ИИ-провайдеры и выбор моделей

Администратор при установке или позже в `sudo aibot` **отмечает несколько провайдеров, вводит отдельные ключи, выбирает модели каждого провайдера**, назначает модель по умолчанию. Участники видят только разрешённые модели, не имеют доступа к API-ключам и не могут сами подключать платные модели.

| Провайдер | Бесплатный режим | Пример моделей |
|---|---|---|
| GroqCloud | Постоянная бесплатная квота с ограничениями | GPT-OSS 20B / 120B, Llama 3.1 8B, Llama 3.3 70B |
| Gemini API | Бесплатная квота, может быть недоступна в отдельных странах | Gemini 3.5 Flash-Lite, 2.5 Flash-Lite / Flash (для старых проектов) |
| OpenRouter | Только `openrouter/free` и проверенные `:free` модели; до 50 запросов/сутки без пополнения | Динамический каталог из API |
| Cloudflare Workers AI | 10 000 бесплатных Neurons в сутки; только модели для Free | GLM 4.7 Flash, Gemma 4 26B, Nemotron 3 120B |
| Mistral Studio | Режим Free, ограничения по запросам и доступным моделям | Mistral Small / Large, если разрешены аккаунту |
| Hugging Face | Ежемесячно обновляемый бонус **$0,10** на inference — мало для группового чата | GPT-OSS 120B |
| Собственный HTTPS OpenAI-совместимый API | Стоимость зависит от вашего провайдера — **не включать без проверки тарифа!** | Указанная вручную модель |

**Не включены** сервисы, предлагающие только стартовый одноразовый кредит (например, Cerebras Developer в текущем тарифе). Автоподбор OpenRouter никогда не подключает платные fallback-модели: выбор ограничен бесплатными ID и бесплатным автоподбором. При исчерпании квот отвечает об ошибке без перехода на платный режим. Не привязывайте платный биллинг там, где его можно избежать; внешние тарифы могут меняться.

## Команды для участников ВК

Все настройки доступны в самой беседе и в личных сообщениях боту. Например:

```text
бот меню
бот модели
бот модель 2
бот настройки
бот поиск вкл
бот поиск авто
бот поиск выкл
бот стиль кратко
бот стиль обычно
бот стиль подробно
бот контекст 20
бот сброс
бот, а как ты думаешь?
```

`бот меню` показывает подсказки и кнопки ВК. `бот модели` нумерует только модели, разрешённые сервером. Например, `бот модель 2` сохраняет личный выбор в SQLite; он действует во всех беседах с этим ботом.

**Администратор конкретной беседы** может установить значения по умолчанию для её участников:

```text
бот диалог
бот диалог модель 1
бот диалог поиск авто
бот диалог стиль кратко
бот диалог контекст 20
бот диалог сброс
```

Программа проверяет права через VK `messages.getConversationMembers` и при ошибке **запрещает** изменение общих параметров. Обычные участники могут менять только свои предпочтения. Если личная модель стала недоступной, автоматически выбирается разрешённая модель беседы/сервера.

**Порядок приоритета:** настройки участника → настройки беседы → настройки сервера. Серверные запреты, максимум сообщений, срок хранения и общие лимиты переопределить нельзя.

## Контекст, поиск и конфиденциальность

- По умолчанию: до **30** последних сообщений **за 24 часа** каждой беседы; сохранение истории на **7 дней**.
- Тексты сообщений разных бесед не смешиваются. Ответ модели использует реплики нескольких участников; запросы и фрагменты контекста отправляются выбранному облачному ИИ.
- Поиск в интернете включается по смысловым ключевым словам в режиме «авто» или принудительно по личной настройке «вкл». Внешний поиск DDGS может блокироваться поисковиками.
- Часовой лимит вызовов ИИ и пауза между ответами в каждой беседе защищают бесплатные квоты.
- Настройки пользователя хранятся по VK ID; настройки беседы — по её peer ID. Чтобы удалить все сохранённые сообщения, откройте меню сервера, пункт 7.
- ВК может не передавать все сообщения в зависимости от выданных прав. Уведомите участников, что бот сохраняет часть истории и передаёт контекст внешнему провайдеру.
- Логи не содержат API-ключей. Файл конфигурации ограничен для пользователя root и группы aibot. Токены не отправляются участникам ВК.

## Разработка и тесты

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Состав проекта: `bot.py` — VK Long Poll, `ai_bot/cli.py` — серверное меню, `ai_bot/catalog.py` — каталог бесплатных моделей, `ai_bot/preferences.py` — настройки участника/беседы, `ai_bot/commands.py` — русские команды, `ai_bot/providers.py` — API, `ai_bot/core.py` — база и конфигурация.

Этапы: **1/5** — бот ВК, контекст и установщик; **2/5** — разрешённые модели, API и персональные настройки (эта версия); **3/5** — интеграционная проверка VK/AI, память и UX; **4/5** — защищённая веб-панель (по желанию); **5/5** — устойчивость и стабильный релиз.
