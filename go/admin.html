2. Как подключить ВКонтакте?

Сообщество ВК — отдельная страница (группа или паблик), от имени которой отвечает бот. Беседа — чат с участниками, куда добавляют это сообщество.

  1. Если сообщества нет, создайте его через раздел сообществ ВК.
  2. Узнайте ID: если адрес страницы vk.com/club123456, ID — 123456. При красивом адресе ищите ID в «Управление».
  3. Откройте «Управление» → «Настройки» → «Работа с API» → «Ключи доступа». Создайте токен с разрешением на сообщения. Никому не отправляйте токен.
  4. Включите «Сообщения сообщества», возможности ботов и в «Long Poll API» события message_new и message_event.
  5. Добавьте сообщество в нужную беседу ВК. Администратор беседы должен разрешить чтение доступных сообщений.
  6. На сервере: sudo aibot menu → пункт 1, затем sudo aibot doctor. Проверьте сообщение с упоминанием сообщества.

Названия пунктов ВК могут отличаться между веб-версией и приложением. Бот не увидит сообщения до приглашения.
