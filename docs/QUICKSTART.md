# AI-bot: первая настройка без лишних терминов

После установки откройте:

`sudo aibot menu`

В меню состояния отмечены так: **✓ ВКЛ / ✓ Готово** — функция работает или настроена; **✗ ВЫКЛ / ✗ Не настроено** — выключена или требует действий. Нажмите **0**, чтобы вернуться назад.

## 1. Создайте сообщество ВКонтакте

**Сообщество** — отдельная страница ВК (группа/паблик), которой управляете вы. Это имя бота: от его имени AI-bot будет писать сообщения. **Беседа** — групповой чат ВК с друзьями или коллегами. Это разные вещи!

Если сообщество ещё не создано: откройте [vk.com/groups](https://vk.com/groups), выберите «Создать сообщество» и следуйте инструкциям ВК.

## 2. Найдите ID сообщества

Откройте его страницу. Например, если адрес:

- `https://vk.com/club123456` — ваш ID **123456**.
- `https://vk.com/public123456` — ваш ID **123456**.
- `https://vk.com/my_ai_bot` — это короткое имя страницы, **не ID**. Числовой ID нужно найти в управлении сообществом.

В терминал вводится только число, без слова `club`, адреса или минуса.

## 3. Получите токен ВК

Откройте своё сообщество (нужны права администратора). В веб-версии ВК найдите:

**«Управление» → «Настройки» → «Работа с API» → «Ключи доступа» → «Создать ключ»**.

Разрешите «Сообщения сообщества». Для автоматического включения Long Poll через бота может потребоваться «Управление сообществом». Скопируйте токен. Это секрет, похожий на пароль: **не отправляйте его в чат ВК и не публикуйте в интернете**.

Названия и расположение пунктов могут меняться. Если вы не видите «Работа с API», попробуйте открыть управление сообществом в браузере на компьютере.

## 4. Разрешите сообществу получать сообщения

В **«Управление» → «Сообщения»** включите сообщения сообщества. Затем откройте **«Настройки для бота»**, включите возможности ботов и галочку **«Разрешать добавлять сообщество в беседы»**. В разделе **«Работа с API» → «Long Poll API» → «Настройки»** включите Long Poll, затем на вкладке **«Типы событий»** отметьте два события:

- `message_new` — поступило новое сообщение.
- `message_event` — пользователь нажал кнопку бота.

Это можно попробовать включить из терминального меню AI-bot, пункт **9**, после сохранения токена и ID. Если VK API откажет, включите вручную.

## 5. Подключите ВК к AI-bot

На VDS:

`sudo aibot setup`

Следуйте подсказкам. Вставьте токен, затем числовой ID. Нажмите Enter, чтобы сохранить существующее значение. Токен не будет показан повторно.

Для просмотра инструкции в любой момент используйте:

`sudo aibot guide`

## 6. Подключите бесплатную ИИ-модель

В меню **пункт 2** — «Подключить бесплатный ИИ / выбрать модель». Выберите сервис (например GroqCloud), перейдите по ссылке «Где получить ключ», создайте бесплатный API-ключ и вставьте его.

Для начала проще выбрать **«1. ✓ ВКЛ — автоматически выбирать доступные бесплатные модели»**. Дальше можно изменить модель вручную. Не включайте платные тарифы и биллинг.

**Сервис ИИ** (Groq, Gemini, Cloudflare и др.) — это внешний генератор ответов. Он не имеет отношения к «сообществу ВК», которое используется как имя бота.

## 7. Добавьте сообщество ВК в беседу

Откройте страницу **вашего сообщества**. После включения возможностей ботов там обычно появляется кнопка **«Пригласить в беседу»** или **«Добавить в чат»**. Нажмите её и выберите нужную беседу. Альтернативно откройте настройки нужной беседы → добавление участников или ботов. Администратор беседы должен разрешить боту читать доступные сообщения: пункт может называться **«Доступ ко всей переписке»** или находиться в настройках прав.

Бот не сможет прочитать историю до своего добавления и сообщения, к которым ВК не дал доступ.

Теперь напишите, например:

`[club123456|Мой бот], привет!`

Вместо **123456** подставьте ID вашего сообщества. В ВК можно просто упомянуть сообщество через интерфейс упоминаний.

## 8. Что делать, если бот молчит?

Откройте:

`sudo aibot next`
`sudo aibot doctor`
`sudo aibot logs`

Проверьте, что есть хотя бы одна разрешённая модель, токен ВК актуален, события Long Poll включены, сообщество добавлено в беседу и ему доступна переписка. Диагностика покажет статусы ✓/✗ с подсказками.

## 9. Нужна ли веб-панель?

**Не обязательно.** Всё настраивается через `sudo aibot menu`. Для постоянной веб-панели по домену откройте пункт 8. HTTPS-сертификат получит Caddy, если домен указывает на VDS и порты 80/443 свободны. Если VPN уже использует эти порты, оставьте терминальное меню или локальную панель через SSH — VPN отключать не требуется.
