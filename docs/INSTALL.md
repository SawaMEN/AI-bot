# AI-bot — установка и проверка

Поддерживаются Debian 12+ и Ubuntu 22.04+, systemd, Python 3.10+. На VDS 1 vCPU и 1 ГБ RAM большая локальная модель не нужна: запросы отправляются внешнему бесплатному API.

## Установка и обновление

    curl -fsSL https://raw.githubusercontent.com/SawaMEN/AI-bot/main/install.sh | sudo bash

Если мастер не запустился из-за отсутствия терминала, выполните:

    sudo aibot setup

После повторной установки данные и настройки в /var/lib/ai-bot и /etc/ai-bot сохраняются. Запуск службы:

    sudo systemctl status ai-bot
    sudo aibot doctor
    sudo aibot logs

## Разрешения ВКонтакте

1. В сообществе включите «Сообщения сообщества».
2. В настройках для бота включите возможности ботов и добавление сообщества в беседы.
3. В Управление → Настройки → Работа с API → Ключи доступа создайте токен сообщества с правом на сообщения. Введите его на сервере через sudo aibot. Не отправляйте токен в ВК.
4. В Bots Long Poll API включите события message_new и message_event.
5. В меню sudo aibot пункт 10 может попытаться настроить эти два события автоматически. Требуется явное подтверждение; если API отказал, настройте в ВК вручную.
6. В групповом диалоге администратор должен выдать сообществу «Доступ ко всей переписке» либо права администратора. В разных клиентах ВК управление находится в названии беседы → Участники → Права.
7. Проверьте: один участник пишет реплику, второй упоминает сообщество и задаёт вопрос «а как ты думаешь?». Бот должен учитывать предыдущую реплику.

В самом ВК доступна инструкция «Права и подключение» через кнопку. События до приглашения бота не восстанавливаются.

## Бесплатные API

В меню sudo aibot выберите провайдера, вставьте API-ключ бесплатного аккаунта и включите «Автоматический подбор подтверждённых бесплатных моделей». Можно подключить несколько ИИ, а участники смогут выбирать разрешённые модели через кнопки ВК. Если основная модель недоступна, бот может попробовать ещё одну бесплатную (эту функцию можно запретить на сервере, в беседе или лично).

Важно: не подключайте банковскую карту и платный биллинг. Изменения тарифов у провайдеров не контролируются ботом.

## Локальная веб-панель администратора

Панель не работает постоянно и не открывает публичный порт. На СВОЁМ компьютере откройте SSH-туннель:

    ssh -L 8765:127.0.0.1:8765 USER@SERVER_IP

В открытой SSH-сессии запустите:

    sudo aibot web

В браузере компьютера перейдите по адресу http://127.0.0.1:8765. Имя пользователя: admin. Пароль на текущую сессию появится в терминале. После работы остановите панель Ctrl+C. Порт 8765 НЕ следует открывать наружу в файрволле.

В панели доступны выбор провайдеров и автоматического каталога бесплатных моделей, настройки ключей, глобальные лимиты, основная модель и перезапуск службы. Токены не отображаются после сохранения. Панель защищена одноразовым паролем и CSRF-токеном, работает только на loopback через SSH.

## Диагностика

    sudo aibot doctor
    sudo journalctl -u ai-bot -n 60 --no-pager

Проверяются база SQLite, бесплатные модели, доступ к ВК, разрешения message_new и message_event. Проверка не отправляет платных генераций. Реальную работу внешних API и отправку сообщений ВК нужно дополнительно проверить с действующими ключами.

## Приватность

История сообщений (по умолчанию 7 дней) хранится в SQLite, а фрагменты контекста отправляются выбранному ИИ. При резерве история может отправиться второму ИИ. Уведомите об этом всех участников беседы. В конфиденциальных беседах рекомендуется отключить резерв и AI Horde, где данные могут обрабатываться на волонтёрских машинах.

Входящие события и очередь необработанных запросов сохраняются между перезапусками. Применяются отдельные лимиты вызовов API для сервера, пользователя и диалога. Включение большего количества бесплатных API не отменяет их индивидуальных квот.
