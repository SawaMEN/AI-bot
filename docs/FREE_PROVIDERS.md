# Автоматический каталог бесплатных AI

Программа поддерживает 10 провайдеров, в том числе источники со многими моделями (OpenRouter, AI Horde, Pollinations). В отличие от набора моделей, **провайдер** — это API-сервис. Через один провайдер можно выбирать популярные DeepSeek, Qwen, Llama, Gemma, GPT-OSS и другие.

## Настройка за несколько действий

1. Выполните: sudo aibot menu
2. Откройте «Бесплатные провайдеры и модели».
3. Выберите провайдера. Программа покажет сайт получения бесплатного ключа.
4. Введите ключ, если нужен; для AI Horde доступен анонимный ключ 0000000000.
5. Выберите «Автоматически включать ВСЕ подтверждённые бесплатные модели».
6. Для нескольких уже подключённых сервисов выберите «Автоподбор у всех подключённых».
7. Перезапустите сервис из меню. В беседе ВК упомяните сообщество и откройте кнопкой «Выбрать ИИ».

Списки из динамических API обновляются при старте и каждые 12 часов, ; если каталог недоступен, модели с неподтверждённой ценой отключаются до следующего обновления. При отсутствии подтверждения стоимости модель отключается. Статические проверенные списки остальных сервисов не требуют удалённого обнаружения.

## Что поддерживается

- GroqCloud: GPT-OSS, Llama (бесплатная квота).
- Google Gemini: Gemini Flash/Flash Lite (бесплатная квота).
- OpenRouter: разные бренды через бесплатный маршрутизатор и модели :free с нулевой ценой.
- Cloudflare Workers AI: GLM, Gemma, Nemotron (бесплатная квота).
- Mistral Studio Free: Mistral Small по бесплатной квоте.
- Z.ai: бесплатные GLM Flash.
- SiliconFlow: бесплатные Qwen и DeepSeek.
- ModelScope: бесплатный Qwen через API Inference.
- Pollinations: только текстовые модели с подтверждённой ценой ноль за вход/выход (ключ обязателен).
- AI Horde: бесплатная распределённая сеть волонтёров; регистрация необязательна, но анонимные запросы медленные.

Для закрытых бесед AI Horde не рекомендуется: история может попасть на компьютеры добровольцев. Уведомляйте участников беседы о передаче фрагментов контекста внешним сервисам.

## Как добавить следующего провайдера

Отредактируйте один доверенный файл: go/providers.json (встроен в исполняемый Go-бинарник при сборке)

Для OpenAI-совместимого API достаточно добавить объект со следующими полями:

    {
      "id": "example-free",
      "name": "Example Free API",
      "key_url": "https://example.org/free",
      "type": "openai",
      "endpoint": "https://api.example.org/v1/chat/completions",
      "free_policy": "curated",
      "models": [["confirmed-free-model-id", "Название модели"]]
    }

Этот фрагмент — схема, а не действующий поставщик. Добавляйте только подтверждённые бесплатные модели и реальные HTTPS адреса официального API. Для особых протоколов (не OpenAI Chat Completions) требуется отдельный адаптер.

Политики каталога:
- curated: строгий перечень моделей, которые проверены разработчиками.
- priced_openrouter: только модели :free с явно нулевой ценой входа и выхода.
- priced_pollinations: только модели с явной нулевой ценой обеих текстовых операций.
- volunteer: только проверенные добровольческие сервисы (не следует автоматически присваивать любому новому API).

API-ключи, модель, параметры и URL нельзя задавать из пользовательских сообщений ВК. При добавлении нового провайдера проверяйте условия тарифа, цену и политику передачи данных. Не подключайте платежную карту и платный биллинг.

## Ограничения

Бесплатные тарифы и модели могут изменяться. Переключения на платный fallback нет. Некоторые API могут быть недоступны из страны VDS. Если цены отсутствуют или каталог временно недоступен, динамические модели не используются. Серверу с 1 ядром и 1 ГБ RAM не нужна локальная большая модель: всё выполняется внешним API.

После изменения кода запустите Go-тесты: go test ./go/.... Пересоберите бинарник и проверьте GitHub Actions.
