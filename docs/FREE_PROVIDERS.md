# Бесплатные ИИ для VK-бота — ноябрь 2026

В меню «Подключения» → «Бесплатные ИИ» провайдеры упорядочены: **сначала без регистрации и обязательного ключа**, затем **с регистрацией** (администратор получает бесплатный API-ключ). Внутри групп первыми идут наиболее известные семейства моделей — это приблизительный порядок узнаваемости, не рейтинг по проверенному общему числу пользователей. Каталог включает более 10 бесплатных вариантов, но доступность на вашем VDS подтверждается только реальным запросом.

## Без регистрации

| Сервис | Модели / маршруты | Условия |
| --- | --- | --- |
| G4F Groq | GPT-OSS 120B | Публичный сторонний API, без ключа |
| G4F Gemini | Gemini 2.5 Flash, Flash Lite | Публичный шлюз, не официальный Google API |
| G4F Ollama | Llama 3, Mistral | Шлюз; наличие моделей может меняться |
| G4F Pollinations | `openai` (сервисный маршрутизатор, модель не гарантируется) | Публичный шлюз G4F, не прямой Pollinations API |
| LLMFaucet — **экспериментальный, по умолчанию выключен** | `auto`, `auto:smart` | Документация обещает 20 бесплатных запросов/сутки анонимно, бесплатный необязательный ключ увеличивает лимит до 50; API может быть ещё недоступен |

G4F описывает свои публичные маршруты в https://g4f.dev/docs/ready_to_use.html . Информация о LLMFaucet и его текущем статусе: https://github.com/llmfaucet/llmfaucet .

### Гарантии и ограничения

- «Без регистрации» означает, что **администратору VK-бота не нужно регистрироваться для API**. Для сервисов «с регистрацией» ключ получает только администратор, не каждый пользователь ВК.
- **Бесплатный веб-чат** ChatGPT, Claude, Duck.ai, Perplexity не превращается автоматически в разрешённый бесплатный API для интеграции. Незадокументированные обходы авторизации не используются.
- Наличие модели в каталоге не означает её фактическую работоспособность. Только модели с успешной **проверкой реального ответа на русском языке с сервера** появятся у пользователей VK. Анонимные шлюзы могут прекращать работу, ограничивать доступ или менять модели.
- Прямой современный API Pollinations требует ключ. Бесключевой путь относится только к отдельному шлюзу G4F.
- Бесплатная квота ограничена. Бот не использует платные варианты моделей OpenRouter и не активирует оплату.

### Настройка

`sudo aibot menu` → «Подключения» → «Бесплатные ИИ». Сервисы без регистрации находятся вверху; в остальных есть явная пометка «с регистрацией». Ввод бесплатного ключа доступен в соответствующем пункте меню. Для LLMFaucet ключ **необязателен** — он предусмотрен только для расширения бесплатного лимита.

`sudo aibot check-ai` — повторно проверить подключённые модели из вашего региона VDS. Проверки CI: `go test ./go/...`, `go test -race ./go/...`, `go vet ./go/...`.

Данные беседы, необходимый контекст и сам запрос направляются выбранному стороннему провайдеру. API-ключи хранятся локально в конфиге и не показываются пользователям ВК.
